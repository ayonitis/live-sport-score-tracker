# 🏆 LivePulse — Live Sports Score Tracker

LivePulse is a minimalist, multi-sport tracking platform that brings live scores, upcoming fixtures, and match results together in one place.

🌐 **Live Demo:** [live-sport-score-tracker.vercel.app](https://live-sport-score-tracker.vercel.app/)

## ✨ Features

- ⚽ **Football** — Live scores, fixtures, and results
- 🏏 **Cricket** — Match scores and updates
- 🏀 **Basketball** — Game schedules and results
- 🏉 **Rugby** — Fixtures and match updates
- 🏎️ **Formula 1** — Race schedules and results
- 📅 Browse upcoming matches and completed events
- 🎨 Clean, responsive, and minimalist interface
- 🔄 Sports data powered by external APIs

## 🛠️ Built With

- Next.js
- TypeScript
- Tailwind CSS
- Sports data APIs
- Vercel
